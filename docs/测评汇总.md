# Stage-1 测评汇总

本文档整理当前项目的 coarse/refine、单目深度 scale 校正和匹配几何诊断结果。旧的错误坐标变换结果已删除，不作为实验结论使用。

## 当前统一的深度估计主指标

从本次更新起，稠密单目深度估计统一使用 `scripts/evaluate_confidence.py` 的 learned-confidence 加权几何 scale 校正。Stage-1 certainty 加权、Top-K 和 RANSAC 结果保留作历史消融；由卫星匹配位置回投得到的 camera-z 指标属于匹配几何诊断，不作为单目深度估计主指标。

对每帧所有有效锚点，使用训练好的 confidence head 输出 `c_i`，在 log 空间求加权几何平均：

```text
w_i = c_i / sum_j(c_j)
scale = exp(sum_i(w_i * log(anchor_z_i / mono_anchor_z_i)))
corrected_depth = scale * mono_depth
```

锚点只要求几何 `anchor_z` 和采样到的单目 camera-z 深度有限且为正，并满足最大锚点深度限制；不按 certainty 排序截断，不用 GT/LiDAR 选锚点。稠密评估 mask 固定为有效 LiDAR 深度范围与正的有限单目深度的交集，同帧的所有对比方法共用它。各帧分别计算指标，再对帧取平均。confidence 加权的算术 scale、等权 scale 和 Stage-1 certainty Top-20 仅作为消融。

- 锚点：每帧最多选择 20 个，卫星推算出的锚点深度限制为 `0–80 m`；先排除无效锚点，再按 Stage-1 certainty 降序选择。

### LiDAR 使用边界

LiDAR 不输入模型，也不参与 scale 估计。它只用于：

1. 构造最终稠密深度评估 mask；
2. 计算锚点/深度预测的对照指标。

深度评估使用 `0 < z_gt < 80 m` 的 LiDAR 像素。

### Scale 估计

每个有效锚点计算：

```text
scale_i = anchor_z_i / unidepth_z_i
```

历史协议的 Stage-1 certainty 加权 mean 为：

```text
scale = sum(certainty_i * scale_i) / sum(certainty_i)
```

RANSAC 配置为：

- 相对误差阈值：15%；
- 候选 scale：每个 `scale_i`；
- 内点条件：`abs(scale * predicted_z - anchor_z) / anchor_z <= 0.15`；
- 先选内点最多的候选，平票时选平均内点误差更小的候选；
- 最终 scale：获胜内点的 Stage-1 certainty 加权 mean；
- 锚点不足或没有可靠共识时回退到 Stage-1 certainty 加权 mean。

指标定义为：

```text
AbsRel = mean(abs(pred - gt) / gt)
SqRel  = mean((pred - gt)^2 / gt)
RMSE   = sqrt(mean((pred - gt)^2))
delta_k = fraction(max(pred / gt, gt / pred) < 1.25^k)
```

## 2. 坐标变换规则

这是本次整理中最重要的修正。

### KITTI-360

KITTI-360 的卫星图按正北方向保存，manifest 没有显式的 `satellite_forward_world_xy` 和 `satellite_right_world_xy`。因此使用 north-up 变换：

```text
world_x = center_x + (u - center_u) * meters_per_pixel
world_y = center_y - (v - center_v) * meters_per_pixel
```

正式评估入口会根据 manifest 是否提供显式方向自动选择该变换。

### 自采数据

自采卫星图不是正北朝向，manifest 的 400/400 帧都显式提供了 forward/right 方向。因此使用 ego-oriented 变换：车辆中心在卫星图中心，车头方向朝上，车辆右侧朝右。

之前将 KITTI-360 也套用 ego-oriented 变换，会把 KITTI-360 的 scale 从约 `0.71` 错算成约 `0.44`。该错误结果已删除。

## 6. 评测入口和指标角色

- `scripts/evaluate_confidence.py`：稠密单目深度估计的唯一主指标入口；使用 learned confidence-head 加权几何 scale。
- `evaluation/depth_metrics.py`：AbsRel、SqRel、RMSE、δ1/δ2/δ3 的共享实现。
- `evaluation/anchor_scale.py`：加权 mean 和 RANSAC scale 核心逻辑；不再使用 median 作为 scale estimator。
- `scripts/evaluate_unidepth_anchor_scale.py`：Stage-1 certainty weighted mean/RANSAC 消融；自动区分 north-up 和显式 ego-oriented 卫星图。
- `scripts/evaluate_cached_anchor_scale_ransac.py`、`scripts/evaluate_anchor_scale_threshold_ablation.py`：缓存锚点上的 Stage-1 certainty scale 消融。
- `scripts/evaluate_depth.py`、`scripts/evaluate_matching_ab.py`：由匹配位置回投的 camera-z 几何诊断，不作稠密单目深度主指标。
- `scripts/evaluate_daynight_matches.py`：自采数据 ego-oriented 卫星坐标和 coarse/refine 位置评估。
- `scripts/merge_unidepth_anchor_scale.py`：合并分块的 Stage-1 certainty scale 消融结果。
- `tests/test_anchor_scale.py`：无离群点、含离群点、锚点不足/回退等测试。

训练权重的实际文件名包含 `_epoch_NNN_step_NNNNNN`。`*_latest.pth` / `*_best.pth` 是兼容符号链接；confidence 权重同时记录其配套 Stage-1 文件哈希。
